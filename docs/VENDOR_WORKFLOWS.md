# Vendor workflows

Stage 1 includes test-only paid claim initiation, server-confirmed payment, independent admin decision, unique owner capability and a workspace listing owned tools. It excludes live charging. A User or Creator may hold Vendor access; no fourth account type is created.

Stage 2 completes paid tool submissions, paid edit proposals, verification requests, proof review/revocation/disputes, status notifications and analytics. Later commercial work adds subscriptions and placements. Admin review remains mandatory. Vendors cannot self-award aiBean Verified, modify Last Verified or organic scores, or edit/delete user reviews.
