# Creator resource page contract

Stage 3 deliverable. Public profile `/@handle`; campaign page `/@handle/resource-slug`. A page contains validated structured blocks for the exact resource, creator attribution, related tools/Skills/Playbooks/stacks/events, approved external CTAs and affiliate disclosure. It is not an arbitrary HTML builder. Record campaign attribution and validated downstream clicks. aiBean-managed affiliate URLs are the default; no payout system in MVP.
