# GitHub publication

The owner requested publication of the existing website and the complete audit package to https://github.com/nzagha/aibean.

## Included

- Next.js application source, shared components and brand/font/logo assets.
- Package manifest and lockfile, TypeScript/Tailwind/Next.js configuration.
- Database schema and migration source, scripts, tests and existing CI workflow.
- Documentation and all audit artifacts under docs/audit, including the combined Markdown report, review prompt, machine-readable manifest and ZIP.
- Version 1 and 1.1 source archives and their manifests.
- A placeholder-only .env.example.

## Kept local

- .env.local and other private environment files, including the temporary account credentials, password hash and session secret.
- node_modules, .next, build caches and test output.
- Original Word/Excel/PDF/CSV reference attachments and the original job-description attachment.

The audit's source fingerprints and findings describe its October 7, 2026 snapshot before Git initialization and these publication notes. Preserve those audit artifacts as dated evidence rather than rewriting them to imply all findings are fixed. Subsequent repository changes can be reviewed against their hashes and Git history.

Publishing source to GitHub does not host the application, connect services, apply migrations, create accounts or activate payments. The temporary login credentials do not travel with the source. Follow README.md and docs/TEMPORARY_PASSWORD_LOGIN.md to configure a separate local environment. The audit's dependency, security and launch limitations still apply.
