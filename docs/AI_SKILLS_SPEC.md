# AI Skills contract

Stage 3 deliverable. A Skill is a focused task with intended outcome, author, category/use case/industry, linked tools, ordered instructions, prompts, examples, approved resource files, related Playbooks and publication state. Approved Creators and Admins author; third-party content requires moderation. Public search is scoped to Skills. Save/download access must enforce visibility and ownership. No generic blog-post substitution or unsafe HTML blocks.
