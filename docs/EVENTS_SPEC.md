# Events contract

Stage 4 deliverable. Public events are distinct from behavioral analytics_events. Support virtual/in-person/hybrid formats, organizer, event type, venue, timezone-aware start/end, external registration, related tools/content/taxonomy and moderation state. Approved creators/vendors/organizers submit; admins review. Lifecycle includes draft, pending review, published/upcoming, ongoing, completed/archive, rejected and canceled. Registration remains external and tracked through validated links. No invented public events are seeded.
