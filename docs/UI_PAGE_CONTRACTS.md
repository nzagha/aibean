# UI contracts

Preserve the approved cream/cobalt/orange brand and self-hosted fonts. Primary nav follows v0.3. Playbooks and industry discovery stay reachable via homepage, mobile menu, footer and scoped search. No public Pricing nav entry.

Tool cards show name, category, summary, pricing model, reviews or explicit absence, baseline verification, separate claimed/Verified badges, Last Verified, save and comparison controls. Detail separates best-for/not-best-for, features, integrations, platforms, strengths, limitations, review moderation and ownership claiming.

Directory filters use stable source IDs and a parent-dependent subcategory. Industry pages include native/strong fit only. Compare accepts 2–4 valid tools; unknown data stays explicit. Scored recommendations stay absent until supported. Guest comparison is temporary in-memory state; persistent comparison is later authenticated work.

Later-stage modules have informative, labeled landing pages with no invented live listings. Missing provider setup displays a meaningful state. Protected account/admin routes enforce authorization on the server and mutations. Error/loading/empty states exist. Mobile visual verification was blocked by browser runtime failure in this environment and remains pending.
